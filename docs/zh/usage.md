# 使用手册

[English](../en/usage.md) | 简体中文

五个视图：**牌组**（首页）→ 学习 → 卡片库 → 统计 → 设置。单字母快捷键 `S` `B` `T` `D` 直接跳转，`D` 回首页。

启动：安装版为 `/Applications/Miki.app`（Raycast 输入 `miki` 或 Spotlight/Dock 直接启动，全局单实例——重复启动会唤起已有窗口）；开发调试用 `npm run dev`。

## 牌组（首页）

- 「创建牌组」新建；页面下方两行：今日已学 / 历史累计已学张数，快捷键提示（chips 样式）。
- 表格列：牌组名 / 总数 / 未学习 / 到期；按名称排序（数字感知，`1 xxx` 排在 `2 xxx` 前）。到期 = 此刻已到期可刷的学习/复习卡（不含新卡、未到期与暂停卡）；总数含暂停卡。
- 行尾「…」菜单：**重命名** / **删除**。删除牌组后其下卡片保留在数据文件中，但不再出现在任何视图；删除牌组不可撤销。

## 学习

- `Space` 显示答案；显示答案后 `Space` 或 `3` 评「良好」，`1` 重来、`2` 困难、`4` 轻松。
- 每个评级按钮下方实时预览按下后的下次到期时间（预览不受间隔抖动影响，展示稳定）。
- 队列顺序：学习队列（分钟级步进，到点插回）→ 当日到期复习 → 新卡。只要当日还有复习卡未处理（含今日稍后到点的），就先不出新卡——刷完旧卡才能刷新卡；学习中的回炉卡到点后正常插回，不阻塞新卡。每日不限量。
- 新增/编辑卡片在独立子窗口中进行：可拖出主窗口（含拖到其他屏幕），位置与尺寸跨启动记忆；正反面 Markdown 输入框随内容自动增高（不再固定行高内滚），内容超出时窗口整体上下滚动；选中内容按 `⌘B`（Windows `Ctrl+B`）切换加粗（无选区时插入 `****`），`⌘Z` 可回退。新增模式提交后表单保留，可连续录卡。
- 反引号 `` ` ``（新增/编辑窗口与卡片库编辑面板的正反面输入框）：单按=无选区插一对（光标居中）/有选区包裹行内代码；连续按三下=围栏代码块（有选区包住选区上下各一行 ```，无选区生成空代码块光标落内容行）。检测基于文本形态不限按键间隔：按两下后文本呈 `` ``|`` ``，第三下自动转换。
- 列表续行：列表行末按回车自动补同级标记（有序列表数字递增，缩进沿用）；空列表项上回车退出列表。新增/编辑窗口与卡片库编辑面板均生效。
- `A` 新增卡片、`E` 编辑当前卡、`⌘D` 删除当前卡（软删）、`⌘Z` 撤销最近一次答题或删除（可连续多步）。
- 卡面支持 Markdown、KaTeX 公式与代码高亮；字体与字号在设置页调整。
- 累计「重来」达到 leech 阈值的卡自动暂停（⏸），不再进入队列；在卡片库可解除。

## 卡片库

- 左栏牌组树（「全部牌组」= 所有未删除牌组）；顶部搜索框支持多关键词空格分隔（AND，匹配正反面，大小写不敏感），`⌘F` 聚焦。
- **列**：点列头排序（再点翻转方向，多级排序按点击顺序），右键列头勾选要显示的列；列宽拖列头右缘调整。三处宽度（左栏 / 表格 / 右面板）都可拖动并跨启动记忆。
- **选择**：点击行选中（右侧面板加载正面/反面，编辑后 800ms 自动保存）；`⌘` 点击多选切换、`Shift` 点击范围选择、`⌘A` 全选当前视图。
- **右键行**：修改所属牌组（保留调度进度）/ 重置进度（变回新卡，不可撤销）/ 删除（软删，可撤销）——多选时对整组生效，菜单显示张数。
- 「距现在」列每 60 秒自动刷新；选中状态跨启动恢复。

## 统计

- 五个板块：到期预测 / 复习热力图 / 复习次数 / 卡片状态 / 间隔分布。
- 顶部下拉按牌组筛选，时间范围「近一年 / 全部」切换。
- 到期预测为 38 根等宽时间柱：近一年=未来 365 天均分 38 桶；全部=最远到期到最早逾期的跨度均分 38 桶（逾期积压落在最左侧）。悬停查看每桶的起止区间与张数。

## 设置

- 刷卡字体：类型 + 字号，带实时示例；默认跟随系统、16px。
- leech 阈值：累计重来多少次自动暂停，`0` 关闭。
- 窗口尺寸/位置/最大化跨启动记忆：调整后自动存入工作区 config.json，下次按最近一次的尺寸打开（拔掉外接屏等场景会自动钳回可见屏幕内）。
- 主题切换在顶栏的 ☀️ / 🌙 按钮（浅色为默认），不在设置页。

## 快捷键总表

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 显示答案 / 评「良好」 | `Space` | `Space` |
| 评「重来 / 困难 / 良好 / 轻松」 | `1` `2` `3` `4` | `1` `2` `3` `4` |
| 学习 / 卡片库 / 统计 / 回首页 | `S` `B` `T` `D` | `S` `B` `T` `D` |
| 新增卡片 / 编辑当前卡 | `A` `E` | `A` `E` |
| 删除当前卡 | `⌘D` | `Ctrl+D` |
| 撤销最近答题 / 删除 | `⌘Z` | `Ctrl+Z` |
| 全选当前视图（卡片库） | `⌘A` | `Ctrl+A` |
| 聚焦卡片库搜索框 | `⌘F` | `Ctrl+F` |
| 确认新增 / 编辑窗口 | `⌘Enter` | `Ctrl+Enter` |
| 关闭新增 / 编辑窗口 | `Esc` | `Esc` |

在文本框输入时单字母快捷键自动失效，`Ctrl+C/V` 等组合键在输入框内不受影响。

## 数据与备份

- 数据全部在工作区文件夹（默认 `~/miki-base`，`MIKI_WORKSPACE` 可指定），与代码分离；格式见 [data-format.md](data-format.md)。
- 备份 = 复制整个文件夹；想用 git 管理复习记录也可以（NDJSON 按月分文件，追加友好）。
- **热加载**：应用运行期间从外部改动工作区（如 `git pull` 同步新内容到本机）会自动检测并刷新，无需重启或切换窗口；正在学习的卡不会被清掉（同卡保留答题相位）。
- 程序化读写（脚本 / AI）请走本机 HTTP API 或 MCP，见 [api.md](api.md)。
